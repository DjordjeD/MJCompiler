# MJCompiler

A complete compiler for **MicroJava**, a small Java-like teaching language. It turns `.mj` source into bytecode for the MicroJava virtual machine.

```
source.mj ──► lexer (JFlex) ──► parser + AST (CUP) ──► semantic analysis ──► code generation ──► .obj
```

- **Lexer:** `spec/mjlexer.flex`
- **Parser:** `spec/mjparser.cup`, an LALR grammar with error recovery and AST generation
- **Semantic analysis:** `SemanticAnalyzer.java`, covering type checking, scopes and the symbol table
- **Code generation:** `CodeGenerator.java`, which emits MJ VM instructions and back-patches jumps for conditions and loops

Built for the Compiler Construction course (PP1) at ETF Belgrade. The spec is in the PDF in the repo root.

## Build and run

```bash
./build.sh            # generate the lexer and parser
ant compile           # compile a test program
ant disasm            # inspect the generated bytecode
ant runObj            # run it on the MJ VM
```

Needs Java 8+ and Ant. Every other dependency is in `lib/`.
